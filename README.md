# GeoGraGame

Jogo simples de perguntas e respostas de geografia.

## Como rodar
- Abra o arquivo `index.html` no navegador.

## O que tem
- Menu inicial (Iniciar / Instruções / Créditos)
- Perguntas de múltipla escolha
- Pontuação
