# GeograGame 🎮🌎

Jogo simples de perguntas e respostas sobre Geografia, feito em **JavaScript** usando **p5.js**.  
A ideia é testar conhecimentos de forma rápida, com questões de múltipla escolha e pontuação ao final.

---

## Como jogar

- **↑ / ↓ (setas)**: muda a alternativa selecionada  
- **Enter**: confirma a resposta  
- **ESC**: volta para o menu (a qualquer momento)

No final, o jogo mostra quantas questões você acertou.

---

## O que tem no jogo

- Menu inicial com opções: **Iniciar**, **Instruções**, **Créditos**
- **20 questões** de múltipla escolha (4 alternativas)
- Sistema de **pontuação** (soma 1 ponto por acerto)
- Tela final com resultado (quantidade de acertos)

---

## Tecnologias

- **HTML + CSS**
- **JavaScript**
- **p5.js** (biblioteca para desenho e interação)

## Como rodar o projeto

### Opção 1 — Abrindo localmente
1. Baixe/clique em **Code > Download ZIP** ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

> Dica: se o navegador bloquear carregamento de arquivos (imagens/fontes), use a opção abaixo.

### Opção 2 — Usando Live Server (recomendado)
1. Instale a extensão **Live Server** no VS Code.
2. Clique com o botão direito no `index.html`.
3. Selecione **Open with Live Server**.

---

## Observações

- Projeto feito com foco em prática e aprendizado (lógica de telas, teclado, pontuação e organização do código).
- As imagens e fontes usadas ficam na pasta do projeto e são carregadas pelo `preload()` do p5.js.
